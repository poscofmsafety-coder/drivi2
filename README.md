# 드라이비 (Drive-AI) — Scenario 14

출발지·소요 시간·동행·기분을 입력하면 조건에 맞는 드라이브 코스(중간 명소 포함)를 추천하는 웹앱입니다.

## 실행 방법

```bash
npm install
npm start
```

PC 브라우저: http://localhost:3000

## 카카오 실제 장소 데이터 켜기 (선택)

주변 추천(경치/맛집)에 큐레이션 데이터 대신 카카오맵 실시간 데이터를 쓰고 싶으면:

1. `.env.example`을 복사해서 `.env` 파일 생성
2. https://developers.kakao.com 에서 발급받은 **REST API 키**를 `.env`의 `KAKAO_REST_API_KEY=`에 붙여넣기
3. `npm start`로 재시작

키가 없거나, 키가 틀렸거나, 카카오 API가 응답하지 않아도 **앱은 절대 에러 없이** 기존 큐레이션 데이터로 자동 전환됩니다 (`lib/kakaoLocal.js`의 안전장치). 애견동반 모드는 카카오 데이터에 반려동반 여부 정보가 없어서 항상 큐레이션 데이터만 사용합니다.

## 휴대폰에서 접속하기

PC와 휴대폰이 **같은 Wi-Fi**에 연결되어 있어야 합니다.

- 기본 사용(입력/추천/지도/내비 연동): `http://<PC의 사설IP>:3000` (예: http://192.168.0.11:3000)
- 음성으로 출발지 입력까지 쓰려면 반드시 HTTPS로 접속: `https://<PC의 사설IP>:3443`
  - 자체 서명 인증서라서 "안전하지 않음" 경고가 뜹니다 → 고급 → 계속 진행을 눌러주세요.
  - Web Speech API(음성 인식)는 보안 연결(https)에서만 동작하는 브라우저 정책 때문입니다.
- PC의 사설 IP는 서버 실행 시 콘솔에 함께 출력됩니다.
- 휴대폰에서 접속이 안 되면 Windows 방화벽에서 Node.js 인바운드 연결을 허용해야 할 수 있어요(제어판 → Windows Defender 방화벽 → 앱 허용).

## Vercel에 내 앱 올리기 (아주 쉽게, 하나씩 따라하기)

**Vercel(버셀)이 뭐예요?** 내 컴퓨터에서만 켜지는 이 앱을, 인터넷 어디서나 들어올 수 있는 "진짜 인터넷 주소"로 만들어주는 무료 사이트예요. 이렇게 하면 컴퓨터를 꺼도 앱이 계속 켜져 있고, 친구나 가족이 그 주소만 알면 자기 폰으로 바로 쓸 수 있어요.

### 1단계. 터미널 열기
터미널은 컴퓨터한테 글자로 명령을 내리는 화면이에요. (지금 이 대화를 하고 있는 이 창이 바로 터미널이에요.)

### 2단계. 프로젝트 폴더로 이동하기
아래 글자를 그대로 입력하고 엔터(Enter) 키를 누르세요.
```bash
cd "C:\Users\LG\Desktop\posco-vibe-project"
```
→ "내 앱이 들어있는 폴더로 가줘"라는 뜻이에요.

### 3단계. Vercel 실행 명령 입력하기
```bash
npx vercel
```
→ `npx`는 "이 프로그램을 딱 한 번만 빌려서 실행해줘"라는 뜻이고, `vercel`은 아까 말한 그 사이트 이름이에요. 엔터를 누르면 필요한 걸 인터넷에서 잠깐 받아와요. 몇 초에서 1분 정도 걸릴 수 있어요.

### 4단계. 로그인하기 (맨 처음 한 번만 하면 됨)
화면에 로그인하라는 질문이 나오면, 인터넷 브라우저(크롬 등)가 자동으로 열려요.
- "Continue with GitHub"처럼 생긴 버튼이 보이면, 깃허브(GitHub) 계정이 있으면 그걸로 눌러도 되고, 없으면 이메일로 가입해도 돼요.
- 로그인이 끝나면 "성공했습니다" 같은 화면이 뜨고, 다시 원래 터미널 창으로 돌아가면 됩니다.

### 5단계. 질문이 나오면 그냥 엔터만 누르기
터미널이 몇 가지를 물어봐요. 잘 모르겠으면 **그냥 엔터(Enter)만 누르면** 기본값으로 알아서 진행돼요.

| 질문 (화면에 영어로 나와요) | 어떻게 할까요 |
|---|---|
| Set up and deploy? | 엔터 (또는 y 입력 후 엔터) |
| Which scope should contain your project? | 엔터 (내 계정이 자동 선택돼요) |
| Link to existing project? | `n` 입력 후 엔터 (처음이니까 "아니오") |
| What's your project's name? | 엔터 (이름을 자동으로 만들어줘요) |
| In which directory is your code located? | 엔터 (기본값 `./`면 맞아요) |
| 그 다음 나오는 설정 질문들 | 대부분 엔터로 넘겨도 괜찮아요 |

*(화면 문구는 Vercel 버전에 따라 살짝 다를 수 있어요. 헷갈리면 그 화면을 캡처해서 저한테 보여주세요.)*

### 6단계. 잠깐 기다리기
"Building..." 같은 글자와 함께 점(...)이 움직여요. 1~2분 정도 기다려 주세요.

### 7단계. 완성된 주소 받기! 🎉
다 끝나면 이런 식으로 진짜 인터넷 주소가 나와요.
```
https://posco-vibe-project.vercel.app
```
이 주소를 복사해서 아무 브라우저(폰이든 컴퓨터든)에 붙여넣으면 드라이비가 바로 열려요! 이 주소를 카톡으로 친구에게 보내주면 친구도 바로 쓸 수 있어요.

### 8단계. 나중에 앱을 고친 다음, 다시 올리고 싶을 때
코드를 수정한 뒤에는 이 명령을 또 입력하면 돼요.
```bash
npx vercel --prod
```
→ `--prod`는 "이번엔 진짜(정식) 버전으로 업데이트해줘"라는 뜻이에요.

### (선택) 진짜 AI 문구를 쓰고 싶다면
지금은 미리 만들어둔 문구 템플릿으로도 잘 작동해요. 만약 진짜 Claude AI가 문구를 직접 써주길 원하면, Vercel 사이트에서 내 프로젝트 → Settings → Environment Variables 메뉴에 들어가서 `ANTHROPIC_API_KEY`라는 이름으로 API 키를 추가하면 됩니다. 안 해도 전혀 문제없어요.

> 배포는 여러분의 Vercel 계정으로 로그인해야 하는 일이라, 제가 대신 눌러드릴 수는 없어요. 위 순서대로 하나씩 직접 터미널에 입력해 주세요. 막히는 부분이 있으면 그 화면을 그대로 캡처해서 보여주시면 제가 바로 도와드릴게요.

## 구조 (역할 분리)

- **코드가 담당**: 거리·시간 계산(`lib/distance.js`), 출발지 지오코딩(`lib/geocode.js`), 실시간 날씨 연동(`lib/weather.js`, Open-Meteo), 반경/시간 예산 기반 코스 조합(`lib/routeBuilder.js`), 주유비·휴게소 안내(`lib/fuel.js`)
- **LLM이 담당**: 코스 하이라이트 문구, 명소 소개 문구, 드라이브 팁 (`lib/textgen.js`)
  - `ANTHROPIC_API_KEY` 환경변수를 설정하면 실제 Claude API로 문구를 생성하고, 없으면 템플릿 기반 문구로 자동 대체됩니다.
- **명소 DB**: `data/spots.csv` — 위치·카테고리·소요시간·계절태그·기분태그를 담은 전국 40개 드라이브 명소

## 구현된 기능

- 코스 자동 설계: 출발지 기반 반경/시간 내 명소 조합, 왕복·편도 선택, 예상 총 거리·시간 표시
- 코스 옵션 3개 동시 추천: 카드로 비교해서 마음에 드는 코스를 골라볼 수 있음 (다른 조합으로 다시 추천받기도 가능)
- 반응형 디자인: 휴대폰에서는 카드 스와이프형 레이아웃, 데스크톱(960px 이상)에서는 검색창 고정 + 2단 레이아웃으로 자동 전환
- 날씨 연동: 맑은 날엔 뷰포인트, 흐리거나 비 오는 날엔 카페·맛집 위주로 자동 전환
- 계절 태그 반영: 현재 계절에 맞는 명소 우선 추천
- 주유비 예측 및 장거리 구간 휴게소 안내
- 지도 API 연동: Leaflet + OpenStreetMap으로 실제 경로 시각화
- 드라이브 이력 저장: 내비 버튼을 누른 곳을 브라우저에 기록하고, "안 가본 곳 위주로 추천" 토글로 다녀온 명소를 제외한 코스만 추천 (기획서 확장 미션 항목)
- 애견동반 모드: 동행에서 "🐕 애견동반" 선택 시 반려견 동반 가능한 명소·맛집·카페만 걸러서 추천 (`data/spots.csv`의 `pet_friendly` 컬럼 기준)
- 휴대폰 접속: 같은 Wi-Fi 네트워크에서 HTTP(3000)/HTTPS(3443) 동시 서비스
- 음성으로 출발지 입력: 마이크 버튼 탭 → Web Speech API(ko-KR)로 인식 (HTTPS 또는 localhost 필요, iOS Safari는 미지원이라 버튼이 자동으로 숨겨짐)
- 내비게이션 앱 연동: 각 경유지 카드 + 결과 상단 "티맵으로 바로 출발하기" 버튼으로 티맵/카카오내비/네이버지도 앱 즉시 실행 (딥링크 방식 — 해당 앱이 폰에 설치되어 있어야 동작, 안드로이드 티맵은 미설치 시 플레이스토어로 자동 이동, 카카오내비는 미설치 시 카카오맵 웹으로 자동 대체)
- 다른 코스 추천: 마음에 안 들면 "다른 코스 추천받기"로 이전에 추천된 명소를 제외하고 재추천
- 기분별 주변 추천: 경치 선택 시 코스 외 주변 명소, 맛집 선택 시 주변 평점 높은 맛집·카페를 추가로 카드에 노출 (카카오 API 키가 있으면 실시간 카카오맵 데이터, 없으면 큐레이션 데이터로 자동 전환)
- 관련 블로그 링크: 카카오 블로그 검색 API로 각 경유지별 실제 방문 후기 블로그 2개를 카드에 표시 (`KAKAO_REST_API_KEY` 필요, 없으면 섹션 자체가 조용히 생략됨)

## 참고

- 실제 도로 주행거리는 직선거리에 보정계수(1.3)를 곱한 근사치이며, 평균 속도 60km/h로 시간을 추정합니다. 실제 내비게이션 경로와는 다를 수 있습니다.
- 출발지는 주요 도시 로컬 표에서 우선 매칭하고, 없으면 OpenStreetMap Nominatim으로 조회합니다(무료, 키 불필요).
